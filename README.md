- 💡 **What I Do**: I design and build end-to-end intelligent software—ranging from hybrid semantic search engines with RAG citation verification to production-grade Manifest V3 Chrome extensions powered by local WebAssembly engines (Stockfish) and Google Gemini AI.

- 🏆 **Hackathons & Competitions**: Developed Computer Vision pipelines for Automatic Number Plate Recognition (ANPR) and Trajectory Tracking for the **Smart India Hackathon (SIH)**.
- ⚡ **Fun Fact**: If a browser task takes more than three clicks, I’ll probably build a Chrome extension to automate it!
